设置

    

      

        
        
        
        
        
        
      

      

        

          
启用 // 唤醒
在任意输入框快速输入两个斜杠，弹出提示词浮框。关闭后 // 只是普通文字。

            

          
唤醒方式
0.5 秒内连续输入 //（小键盘 / 也算）。https:// 这类冒号后的斜杠不会触发。选中提示词后自动删掉 // 再插入；按 Esc 取消则保留 //。

            //

          
浮框位置
跟随文本光标（取不到时退回鼠标位置），或总是跟随鼠标。

            

          
列表显示正文预览
浮框中每条提示词下方显示一行正文。

            

          
全屏程序中不唤醒
游戏、幻灯片放映、全屏视频时输入 // 不弹出。

            

          
排除的程序
在这些程序里输入 // 不会弹出。也可以在浮框里点「在此程序中停用」。

            

            

              
              
            

            

          

          
诊断信息
—

        

        

          
主题
「跟随系统」会随 Windows 的深色/浅色模式自动切换，浮框同样适用。

            

        

        

          
默认排序
筛选 / 搜索时列表的默认排序方式。

            

          
应用角色系统提示
复制结果、预览与 AI 试跑时，自动前置当前角色的系统提示（可用「---」分隔）。

            

          
数据维护
完整备份包含提示词、设置与版本历史。

            

              
              
            

          

        

        

          

            

              
模型配置

              
支持国际（OpenAI / Anthropic / Gemini）、国产（通义、智谱、DeepSeek、Kimi、百川、豆包）与聚合（OpenRouter、SiliconFlow、一API 自定义）。API Key 仅存本机（Windows 使用 DPAPI 加密），不会写入日志。未配置时应用仍可离线使用。

            

            

              
            

            

          

        

        

          
开机自启
登录 Windows 后在托盘静默启动，随时输入 // 唤醒。

            

          

              
以管理员身份启动（可在管理员窗口中唤醒）
                
                  Windows 不允许普通程序接收“以管理员身份运行”的窗口里的按键（权限隔离），所以默认在这些窗口中输入 // 不会弹出。

开启后会创建一个 Windows 计划任务，让提示词 Builder 以管理员身份启动：只在开启时确认一次 UAC，以后开机自启、双击图标打开都不再弹窗。

关闭后删除该计划任务，恢复普通权限。
注意：管理员身份下无法从资源管理器拖放文件到窗口。
              

              
默认关闭。开启时需要确认一次 UAC。
