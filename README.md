# 提示词 Builder 2.6

用 **Markdown + 变量** 写提示词 → 自动生成表单 → 调试 → 在**任意输入框输入 `//`** 弹出浮框，选中即插入。

核心仍是四件事：「Markdown 变量 → 表单」「多个提示词管理」「调试」「输入 // 唤醒的快捷浮框」。2.9.0 在此之上补齐**提示词全生命周期**，并在 2.8 升级为**角色 › 分类 › 提示**三级库与完整开发者内置套件：标签 / 收藏 / 置顶、版本历史与对比、填写历史、归档与备份、本地使用统计；2.9 新增 **44 个技能蒸馏模板（每 skill 一条完整流程，共 52 条）**，覆盖 AI 协作、设计评审、产品经理与教育教学（见 `docs/CHANGELOG.md`）。

## 2. 变量语法

| 写法 | 含义 | 生成的控件 |
|---|---|---|
| `{{名字}}` | **必填**变量 | 单行输入框 |
| `{{名字\|默认值}}` | 可选变量，留空时用默认值 | 单行输入框（占位显示默认值） |
| `{{名字\|}}` | 可选，默认为空 | 单行输入框 |
| `{{正文:多行}}` | 多行文本（别名：`长文本` `multiline` `long` `textarea`） | 多行文本框 |
| `{{字数:数字\|300}}` | 数字（别名：`number` `num`），会校验 | 数字输入框 |
| `{{语气:正式/轻松/幽默\|正式}}` | 下拉选择，选项用 `/` 分隔 | 下拉框 |
| `{{名字:单行}}` | 显式单行（默认就是单行） | 单行输入框 |
| `\{{` | 输出字面量 `{{`，不当变量（`\{{名}}` 整段原样输出） | — |
| `{{{名}}}` | 外层多余的花括号原样保留，输出 `{值}` | — |

**不用记语法**：编辑器工具栏「插入变量 ▾」（`Ctrl+I`）可一键插入以上每种写法，插入后变量名已选中，直接输入即可；先选中一段文字再插入，会把它变成变量名；菜单下方还能再次插入已有变量。

规则：
- 冒号可用全角 `：`；控件提示和默认值可组合：`{{名:多行|默认}}`。
- 同名变量在表单里只出现一次；控件类型与默认值**以第一次出现为准**（冲突会在调试页提示）。
- 有默认值 = 可选；无默认值 = 必填。留空的必填变量在结果中保留原占位符 `{{名}}`，方便发现。
- 代码块（```` ``` ```` / `~~~`）里的括号问题只作提示，不报错；JSON 示例里的 `}}` 也只作提示。
- Windows 换行（CRLF）自动统一；变量不能跨行（跨行通常是漏了 `}}`）。

## 3. 调试面板

每个提示词都有：
- **变量解析表**：变量名、是否必填、默认值、控件类型（下拉显示选项）、所在行、出现次数。
- **测试表单**：按变量自动生成；「保存测试值」后每个提示词各自记住一套测试值。
- **实时预览**：纯文本（未填写的必填项高亮）/ Markdown 渲染两种视图。
- **语法与校验提示**（点击跳到对应行或表单项）：括号不配对、空变量名、非法变量名、多余的 `}}`、下拉选项为空/重复、下拉默认值不在选项内、数字默认值非数字、同名变量控件或默认值冲突、必填未填、数字/下拉测试值不合法、测试值里有已删除的变量、正文为空。
- **字数统计**：模板与渲染结果分别统计字符、不含空白字符、中文字符、词数（中文按字计）、行数。
- **一键复制**渲染结果（不进入 Windows 剪贴板历史）。

## 4. 输入 // 唤醒快捷浮框

在任意程序的输入框里**快速连续输入两个斜杠 `//`**（0.5 秒内、中间不按其他键；主键盘和小键盘的 `/` 都算）：

- 两个 `/` 都会照常输入到你的输入框里，程序**只监听不拦截**；单独一个 `/` 或 `?` 完全不受影响。
- 不会触发的情况：冒号后的斜杠（`https://`、`file:///`）、按住 `/` 自动连发、`Ctrl/Alt/Win` 组合键、两个 `/` 之间按了其他键或间隔超过 0.5 秒、两个 `/` 落在不同窗口。


1. 浮框出现在**文本光标下方**（下方放不下则翻到上方），无边框、置顶、圆角阴影，主题与主程序一致。
2. 搜索框自动聚焦，输入即过滤（空格分隔多个关键词）；最近用过的排在前面；`↑/↓`（或 Tab）、`PageUp/PageDown`、`Home/End` 选择，`Enter` / 单击插入。每项显示名称和一行预览（可在设置中关闭预览）。
3. 只有默认值的提示词**直接插入**；有必填变量时浮框内出现精简表单（自动填入上次的值）：`Enter` 下一项 / 最后一项时插入、`Ctrl+Enter` 立即插入（多行框里 `Enter` 换行）、`Esc` 返回列表。想改默认值时按 `Shift+Enter` 先填表再插入。
4. 插入时：焦点回到原窗口 → **先核对光标前确实是 `//`** → 自动删掉 `//`（两次退格）→ 粘贴 → **恢复你原来的剪贴板内容**（包括图片、文件等格式）。
   - 核对方式：标准编辑框直接读取文字；浏览器、Office、VS Code 等通过 UI Automation 读取。
   - 光标前不是 `//`（例如编辑器自动补全把 `/` 改掉了、输入法把按键吃进了组字）→ **不删任何字**，直接插在光标处，绝不误删你的文字。
   - 读不到文字时：日文/韩文输入法处于开启状态则不删（避免删掉组字内容），其余情况照常删除 `//`。
5. 浮框底部「在此程序中停用」：一键把当前程序加入排除列表（可在设置里恢复）。
6. 不想用浮框？按 `Esc` 或点浮框外面，浮框关闭，`//` 原样保留，不会发送任何按键。

**速度**：浮框窗口在后台常驻并预先渲染好列表（隐藏时用 DWM 隐身 + 停放在屏幕外同 DPI 位置），按下第二个 `/` 后只需定位光标、移动窗口、取消隐身，不重新创建、不重新绘制。

### 光标定位怎么做的
依次尝试，取到即止，结果必须落在前台窗口内才采用：
1. `GetGUIThreadInfo` 的系统插入符（记事本、大部分 Win32 / WinForms / WPF 编辑框）；
2. MSAA `OBJID_CARET`（部分自绘控件、Office）；
3. UI Automation `TextPattern2.GetCaretRange` / 选区矩形（Chrome、Edge、VS Code、Electron 等）；
4. 都取不到 → 鼠标位置（设置里也可固定「跟随鼠标」）。

多显示器 / 不同缩放：全部按物理像素计算，浮框尺寸按目标显示器 DPI 缩放，并夹在该显示器工作区内，不会超出屏幕边缘。

### 设置
托盘图标（双击打开主窗口；右键「暂停 // 唤醒」/ 退出）+ 设置面板（左侧分类）：
- **唤醒**：启用开关、跟随光标/鼠标、列表预览、全屏程序中不唤醒、排除的程序（标签式增删，附 VS Code / Visual Studio / JetBrains / Windows 终端 / 远程桌面 一键添加；默认不排除任何程序——这些编辑器输入 `/` 时并不会自动补全，是否排除取决于你是否常在其中写 `//` 注释）、诊断信息。
- **外观**：跟随系统 / 浅色 / 深色。
- **启动与权限**：开机自启；**以管理员身份启动（可在管理员窗口中唤醒）**——见下文。
- **关于**：版本、数据文件夹、新手引导、快捷键。

## 5. 稳定性与限制（请务必阅读）

- **管理员窗口**：Windows 的权限隔离（UIPI）不允许普通权限进程接收「以管理员身份运行」的窗口里的按键，所以默认在这类窗口里输入 `//` 不会弹出（`//` 只是普通文字）。
  - 需要时打开「设置 → 启动与权限 → 以管理员身份启动」：程序会创建计划任务 `PromptBuilder\ElevatedStart`（最高权限、仅当前用户、交互式登录），**只在开启时确认一次 UAC**，以后开机自启、双击图标打开都直接以管理员身份运行，不再弹 UAC。
  - 默认关闭；关闭此项会删除该计划任务（需再确认一次 UAC）。卸载程序时也会删除它。
  - 管理员身份下无法从资源管理器把文件拖进窗口（Windows 限制）；标题栏会显示「管理员」标记。
- **安全软件**：本程序使用标准的低级键盘钩子（`WH_KEYBOARD_LL`）。若被安全软件拦截或钩子失效：
  - 看门狗检测到钩子「有键盘输入却长时间收不到回调」会自动重装；
  - 仍然不行时，请在安全软件里把 `PromptBuilder.exe` 加入信任。
- 钩子回调只做最少的事并立即返回，不拦截任何按键，不会拖慢打字；程序自己发出的按键带标记，不会被自己再次拦截。
- 删除 `//` 前会先核对光标前的文字（见上文）；极少数既读不到文字、又会改写 `/` 的程序，仍建议加入「排除的程序」。
- 个别程序（游戏、远程桌面、某些终端）取不到光标位置，浮框会出现在鼠标处；个别程序不接受 `Ctrl+V` 粘贴，此时请用主窗口「复制结果」。
- 剪贴板恢复：粘贴后约 0.45 s 恢复；如果这期间剪贴板被其他程序改写，则不覆盖（以免误删你新复制的内容）。
- **只在原窗口粘贴**：插入前会确认焦点已回到你按键时的窗口；如果回不去（例如被其他窗口抢了焦点），不会把内容粘贴到别的窗口，而是留在剪贴板里，你可以手动 `Ctrl+V`。
- **不会误触发**：桌面/任务栏、菜单展开或拖动窗口时、全屏程序（游戏、放映，可在设置关闭）、「排除的程序」里，输入 `//` 不弹出。

## 6. 导入 / 导出与数据

- 导出：整个提示词库（JSON）或当前提示词（`.md`）。
- 导入：提示词库 JSON（也兼容 2.x 的模板导出 / 整库备份），或一个/多个 `.md` 文件（文件名即提示词名）。同 ID 覆盖，其余新增。
- 数据目录：`%LOCALAPPDATA%\PromptBuilder\`（`prompts.json`、`settings.json`）。
- **数据安全**：每次保存先写临时文件并落盘再原子替换，同时保留上一版 `prompts.json.bak`；启动时在 `backups\` 留快照（最多 10 份），导入前也会先备份。文件损坏时自动从备份恢复，损坏文件另存为 `prompts.corrupt-时间.json`。
- 日志：`%LOCALAPPDATA%\PromptBuilder\logs\promptbuilder.log`（崩溃信息也写在这里）。
- **从 2.x 升级**：首次启动自动把 `templates.json` 中你的模板（含上次填写的变量值 → 测试值）迁移为新版提示词；未使用过的旧内置模板不迁移。旧文件全部移到 `legacy-2.x\` 子目录保留，**不会删除**。
