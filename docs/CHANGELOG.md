### 角色级系统提示
- 每个角色（分组）可保存可选 `system_prompt`；旧数据迁移为空字符串。
- 角色行「系统提示」编辑（含内置角色本地覆盖）；复制 / AI / 预览可前置角色设定（设置默认开启），芯片「含角色设定」。

- 点击条目可跳转编辑器行或变量表单。

### 版本对比 Diff
- 版本历史支持勾选两个快照（或与当前）对比；统一 / 并排行 diff（名称+正文），高亮增删。

### 用例 / 黄金样例
- 每提示词最多 10 个用例（`cases`）；表单页「用例」区：增删改、填入表单、保存为用例、跑测（有 AI 则调用，否则 dry-run 与期望比对）。

## 2.9.1 — 取消分步拆分提示词

每个 skill 仅保留一条完整端到端模板，不再拆成「第一步 / 第二步 / Step N」子提示。

- 删除 43 条带「步骤」标签的拆分提示；内置技能提示由 95 条减至 **52** 条（44 个技能）。

## 2.6.1 — 紧急修复：主窗口显示「未找到文件 ERR_FILE_NOT_FOUND」

### 修复
- **安装 2.6.0 后主窗口打不开界面，只显示 Edge 的「未找到文件」错误页**。原因：2.6.0 为了让主题在首帧就生效，在界面地址后面加了 `?theme=system`；而 Windows 上的 WebView2 会把本地文件地址里的 `?` 转义成 `%3F`，于是去找一个名为 `index.html%3Ftheme=system` 的文件，自然找不到。浮框也受同样影响
- 界面地址不再带任何参数：上次使用的主题改为保存在界面本地存储里，首帧即可按主题显示，不闪烁；真正的设置随后由程序同步
- 你的提示词和设置数据不受影响，覆盖安装 2.6.1 即可恢复
- 顺带修复：一行里有大量 `\{{` 转义时，变量识别会越来越慢（耗时随长度平方增长），现在与正文长度成正比

### 防止再犯
- 界面文件统一从安装目录（程序自带资源目录）定位，与当前工作目录无关；开始菜单、桌面快捷方式、安装完成后「立即运行」、开机自启、管理员计划任务都走同一套路径
- 加载后会确认显示的确实是程序界面，而不是浏览器错误页。万一失败，主窗口会显示「界面加载失败」说明页，写明缺失的文件、实际地址和日志位置，并记录到日志（不再只是一页看不懂的浏览器报错）
- 自检新增两项：检查每个界面地址都不带参数、对应文件和引用的样式 / 脚本都在安装包里；打包时会**真正打开一次主窗口和浮框**（从系统目录启动，模拟快捷方式），确认两个页面都正常显示，否则打包失败
